# Entity Management System

The Entity Management System (EMS) is an orchestration service responsible for defining, tracking, and coordinating the lifecycle of entities within a larger Data Management System (DMS).

## Key Features

- **Identity Assignment**: Assigns canonical identity to entities
- **State Tracking**: Tracks entity and workflow state over time
- **Workflow Coordination**: Resolves applicable policies and issues workflow intent
- **Event Emission**: Emits lifecycle and state-change events
